# DepRadar Copy Guidelines

Version: 1.0

---

# Purpose

Every word inside DepRadar should help developers understand their work.

The interface should feel calm, intelligent, and trustworthy.

Good copy reduces confusion.

Great copy makes software feel human.

---

# Brand Voice

DepRadar communicates like an experienced engineering teammate.

It should feel:

- Professional
- Calm
- Thoughtful
- Helpful
- Honest
- Clear

It should never feel:

- Robotic
- Overly enthusiastic
- Corporate
- Sales-focused
- Condescending

---

# Writing Principles

## 1. Clarity First

Prefer:

"Replay is ready."

Instead of:

"Replay generation has successfully completed."

---

## 2. Be Direct

Say exactly what happened.

Avoid unnecessary words.

Good:

"Session completed."

Avoid:

"Congratulations! Your coding session has now been successfully completed."

---

## 3. Never Blame Users

Instead of:

"You entered an invalid project."

Use:

"We couldn't find that project."

Focus on the problem.

Not the person.

---

## 4. Explain The Next Step

Every message should answer:

"What should I do next?"

Example

Replay unavailable.

↓

Complete a coding session to unlock Replay.

---

## 5. Speak Naturally

Write the way experienced engineers communicate.

Avoid marketing language.

Avoid buzzwords.

Avoid unnecessary excitement.

---

# Tone By Context

## Greeting

Warm.

Professional.

Example

Good morning, Sanket.

Welcome back.

---

## Success

Quiet confidence.

Examples

Replay is ready.

Health report generated.

Session saved.

Avoid

Awesome!

Fantastic!

Great Job!

---

## Loading

Describe what is happening.

Good

Preparing your development story...

Analyzing today's session...

Building Replay...

Avoid

Loading...

Please wait...

---

## Empty States

Explain why.

Explain how.

Example

No completed sessions yet.

Finish a coding session and Replay will appear here.

Never use

No data.

Nothing found.

Empty.

---

## Error States

Stay calm.

Explain the issue.

Suggest the next action.

Example

We couldn't connect to the API.

Verify the backend is running and try again.

Avoid

Fatal Error

Unexpected Exception

Operation Failed

---

## Replay

Replay should feel cinematic but understated.

Examples

Replay ready.

Resume Replay.

Replay complete.

Return to today's session.

Avoid

Watch now!

Start experience!

---

## Reflection

Reflection should feel thoughtful.

Examples

Strong focus throughout the session.

Several context switches were observed.

The session concluded naturally.

Avoid

Excellent work!

Productivity increased!

Performance score:

---

## Health

Health never judges.

Good

This session remained focused.

Frequent interruptions were observed.

The session ended unexpectedly.

Avoid

Poor productivity.

Bad session.

Needs improvement.

---

## AI Features

AI should remain humble.

Good

Based on today's session...

One possible explanation...

This pattern may indicate...

Avoid

The AI knows...

Definitely...

Guaranteed...

---

# Buttons

Use verbs.

Examples

Replay

Continue

Resume

Review

Explore

Open Session

Return

Avoid

Click Here

Go

Start Now

Submit

---

# Notifications

Keep notifications short.

Replay completed.

Session saved.

Health report updated.

Avoid long paragraphs.

---

# Confirmation Dialogs

Be explicit.

Delete Session?

This action cannot be undone.

Buttons

Delete

Cancel

Avoid

Are you really really sure?

---

# Numbers

Always provide context.

Bad

94%

Good

Focus

94%

Never display isolated numbers.

---

# Dates & Time

Prefer relative time.

Today

Yesterday

2 hours ago

This week

Only show absolute timestamps where necessary.

---

# Accessibility

Avoid relying on color.

Every message should remain understandable through text alone.

Screen reader users should receive equivalent meaning.

---

# Consistency Rules

Use the same words everywhere.

Always use:

Replay

Reflection

Session

Workspace

Timeline

Insights

Avoid creating synonyms.

Example

Never alternate between:

Replay

Playback

Story

Movie

Choose one.

---

# Things We Never Say

Awesome!

Super!

Amazing!

Oops!

Uh oh!

Boom!

Magic!

Powered by AI!

AI-first!

Revolutionary!

Developers value honesty over hype.

---

# Product Personality

If DepRadar were a teammate, it would be:

Thoughtful.

Patient.

Observant.

Never loud.

Never distracting.

Always helpful.

---

# Final Principle

The best interface copy disappears.

Users should remember what they learned,

not the words that delivered it.

Every sentence should earn its place.

---

## DepRadar Design Manifesto

Every design decision should help developers understand their work more clearly.

If a feature, animation, interaction, or sentence does not improve understanding, it does not belong in DepRadar.
